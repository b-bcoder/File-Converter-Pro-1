# Snel starten met File Converter Pro

## Installeren

1. Open de map `release`.
2. Start `File Converter Pro Setup 0.0.3.exe`.
3. Volg de installatiestappen van Windows.
4. Open File Converter Pro via het Startmenu of de snelkoppeling.

Gebruik de volledige `.exe`. De bestanden `.blockmap` en `.__uninstaller.exe` zijn geen installatiebestanden.

## In 5 stappen

1. Start `File Converter Pro`.
2. Klik op `Browse Files` of `Browse Folder`.
3. Kies het gewenste uitvoerformaat.
4. Klik op `Convert All`.
5. Klik op `Download` om het resultaat op te slaan.

Je kunt bestanden ook naar het venster slepen.

## Belangrijk

De app controleert bij het starten van de conversie of elk bronbestand nog beschikbaar is op de oorspronkelijke locatie. Als een bestand is verwijderd, verplaatst of niet meer toegankelijk is, verschijnt er een foutmelding en wordt de conversie van dat bestand niet voortgezet. Voor de andere bestanden gaat de conversie gewoon door.

## Handige tips

- Gebruik een geldig en niet-beschadigd bronbestand.
- Kies een passende resolutie voor het gewenste resultaat.
- Grote video- en audiobestanden kunnen langer duren.
- Meerdere resultaten kun je samen als ZIP downloaden.
- Druk op `F11` om fullscreen aan of uit te zetten.

De app verwerkt bestanden lokaal. Bestanden worden niet geüpload.
