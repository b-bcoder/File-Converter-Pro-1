# File Converter Pro 快速开始

## 安装

1. 打开 `release` 文件夹。
2. 运行最新的安装程序，例如 `File Converter Pro Setup 1.0.2.exe`。
3. 按照 Windows 安装步骤操作。
4. 从开始菜单或快捷方式打开 File Converter Pro。

请使用完整的 `.exe` 安装程序。`.blockmap` 和 `.__uninstaller.exe` 文件不是安装程序。

## 五个步骤

1. 启动 `File Converter Pro`。
2. 点击 `Browse Files` 或 `Browse Folder`。
3. 选择需要的输出格式。
4. 点击 `Convert All`。
5. 点击 `Download` 保存结果。

也可以将文件直接拖入窗口。

## 音频转录

添加音频文件，选择 `TXT` 生成文本或选择 `SRT` 生成字幕，然后点击 `Convert All`。Whisper 已包含在安装程序中并在本地运行；不需要 MSYS2 或互联网连接。WAV 文件会自动标准化。

## 重要提示

应用在开始转换时会检查每个源文件是否仍位于原来的位置。如果文件已被删除、移动或无法访问，应用会显示错误消息，并停止转换该文件。其他文件的转换会照常继续。

## 快速提示

- 使用有效且未损坏的源文件。
- 根据需要选择合适的分辨率。
- 大型视频和音频文件可能需要更长时间。
- 多个结果可以一起下载为 ZIP 文件。
- 按 `F11` 切换全屏模式。

应用会在本地处理文件，文件不会被上传。

## 背景

点击齿轮图标，在设置中选择 `添加背景` 或 `更改背景`。选择 `关闭背景` 可恢复默认背景。请使用与屏幕宽高比相同的图片，否则背景可能会变形。
